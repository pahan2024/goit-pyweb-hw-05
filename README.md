# Домашнє завдання №5 — Асинхронний HTTP-клієнт та WebSocket-чат

Цей проєкт складається з двох частин: консольної утиліти для отримання архівних курсів валют ПриватБанку та WebSocket-чату, який підтримує асинхронні запити курсів валют за допомогою команди `exchange`.

---

## 🏗️ Архітектура та принципи SOLID

Під час проектування консольної утиліти (`main.py`) було суворо дотримано принципів **SOLID**:

1. **Single Responsibility Principle (Принцип єдиної відповідальності):**
   Кожен клас виконує лише одну задачу:
   * `DateProvider` — виключно генерує список потрібних дат.
   * `PrivatBankClient` — відповідає тільки за виконання мережевих запитів до API та обробку помилок з'єднання (`aiohttp.ClientSession`).
   * `CurrencyFormatter` — займається лише парсингом сирої відповіді від банку та приведенням її до потрібної бізнес-структури.
   * `CurrencyUtility` — оркестратор (Фасад), який збирає все разом та координує виконання.

2. **Open/Closed Principle (Принцип відкритості/закритості):**
   Клас `CurrencyFormatter` спроектований так, що його логіка закрита для модифікації, але відкрита для розширення. Ми можемо передавати динамічний список будь-яких додаткових валют (`PLN`, `GBP` тощо) через конструктор, не змінюючи внутрішній код парсингу.

3. **Liskov Substitution Principle (Принцип підстановки Барбари Лісков):**
   Взаємодія побудована на чітких контрактах (передача готової сесії `ClientSession` в клієнт), що дозволяє за потреби підставити будь-який інший асинхронний HTTP-клієнт з аналогічним інтерфейсом.

4. **Interface Segregation Principle (Принцип розділення інтерфейсів):**
   Класи не перевантажені зайвими методами. Клієнт знає лише як завантажувати, форматувальник — як очищати дані. Сервер чату використовує лише необхідні йому методи клієнта ПриватБанку.

5. **Dependency Inversion Principle (Принцип інверсії залежностей):**
   `PrivatBankClient` не створює асинхронну сесію всередині себе. Замість цього `ClientSession` впроваджується (Dependency Injection) ззовні через конструктор, що спрощує тестування та керування життєвим циклом з'єднань.

## 🛠️ Технологічний стек

* **Python 3.11+** (з використанням `asyncio`)
* **aiohttp** — для неблокуючих HTTP-запитів до API ПриватБанку.
* **websockets** — для реалізації сервера чату.
* **aiofile & aiopath** — для асинхронного, неблокуючого логування подій у файл.

---

## 🚀 Інструкція з запуску

### 1. Встановлення залежностей
```bash
pip install aiohttp websockets aiofile aiopath
```

### 2. Запуск консольної утиліти
Повертає курс EUR та USD (а також додаткових валют за бажанням) за останні $N$ днів (обмеження від 1 до 10 днів):
```bash
# Базовий запит (USD, EUR) за 2 дні
python main.py 2

# Запит за 3 дні з додаванням валют PLN та GBP
python main.py 3 PLN GBP
```

### 3. Запуск WebSocket-чату
1. Запустіть сервер:
   ```bash
   python server.py
   ```
2. Відкрийте файл `index.html` у браузері (можна у кількох вкладках для тестування чату).
3. Напишіть у чаті команду для отримання курсу:
   * `exchange` — курс за сьогодні.
   * `exchange 3` — курс за останні 3 дні.

Кожен виклик команди в чаті асинхронно записується у файл логів `exchange_commands.log`.
